# Sample Data

## Purpose

This directory contains small, non-sensitive datasets used for development, testing and demonstrations.

## Planned Contents

- Example truck profiles.
- Sample origin and destination pairs.
- Synthetic route scenarios.
- Example configuration files.
- Test fixtures for validating application behavior.

## Data Guidelines

- Do not commit credentials, personal information or confidential commercial data.
- Clearly identify synthetic and illustrative data.
- Document the source, license and limitations of external datasets.
- Do not present unverified restriction data as authoritative.
