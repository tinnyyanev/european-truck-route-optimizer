# Contributing

Thank you for your interest in European Truck Route Optimizer.

## Development workflow

1. Create a branch from `develop`.
2. Use a descriptive branch name, such as `feature/truck-profile` or `fix/route-validation`.
3. Keep changes focused and small.
4. Add or update tests when changing application behavior.
5. Update documentation when introducing architectural or behavioral changes.
6. Open a pull request against `develop`.

## Code quality

Contributions should prioritize readability, maintainability, type safety and clear error handling.

Security-sensitive changes must be reviewed carefully. Do not commit credentials, API keys, personal data or production configuration.

## Issues and pull requests

Describe the problem, expected behavior and proposed solution. Include reproduction steps for bugs and tests or screenshots when relevant.

Do not claim that a route is legally compliant unless the required restrictions and supporting data have been verified.
