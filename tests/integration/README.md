# Integration Tests

## Purpose

This directory contains tests that verify interactions between application components.

## Testing Scope

- API endpoint behavior.
- Request and response validation.
- Integration between the API and optimization engine.
- Database interactions when persistence is introduced.
- Routing-provider adapter behavior.
- Error handling when dependencies are unavailable.

## Guidelines

Integration tests should use controlled test environments and avoid depending on live external services unless explicitly intended.
