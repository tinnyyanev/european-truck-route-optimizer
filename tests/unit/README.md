# Unit Tests

## Purpose

This directory contains unit tests for individual functions and components of the application.

## Testing Scope

- Input validation.
- Truck profile validation.
- Route scoring and comparison.
- Operating cost calculations.
- Error handling.
- Optimization logic.

## Guidelines

Unit tests should be fast, deterministic and independent of external services whenever possible.

Use synthetic data and test both expected behavior and edge cases.

## Development Status

**Status:** Planned.

Tests will be added alongside the implementation of each component.
