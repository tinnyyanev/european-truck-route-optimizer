# Route Scenarios

## Purpose

This directory contains representative end-to-end scenarios for evaluating route-planning behavior.

## Planned Scenarios

- Routes within Spain.
- Cross-border routes between Spain and France.
- Routes between France and Germany.
- Different truck dimensions and weight profiles.
- Alternative routes with different distances and estimated costs.
- Missing, conflicting or incomplete restriction data.
- Routing-provider failures and unavailable routes.

## Evaluation Criteria

Scenarios will be used to assess correctness, consistency, error handling and transparency of route results.

A successful test does not, by itself, prove that a route is legally compliant for a particular truck.
