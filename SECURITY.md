# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to the repository maintainer rather than publishing exploitable details in a public issue.

Include a description of the vulnerability, its potential impact and steps to reproduce it.

Do not include real credentials, personal data or sensitive production information in reports.

## Security principles

- Never commit secrets or credentials.
- Validate and constrain user input.
- Use least-privilege permissions.
- Keep dependencies updated.
- Run automated checks on proposed changes.
- Protect sensitive configuration using appropriate secret-management services.

## Scope

This policy covers the application, API, infrastructure configuration and project-maintained automation.
